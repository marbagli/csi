# csi
The code enables the computation of a Cognitive Salience Index (CSI) from a .csv file. Instructions are in the comments of the code. It first appears in Bagli (2025): "Color Entrenchment in Middle-school learners of English as a Second Language: Cognitive Salience Index applied to a bilingual setting"; in Bagli (2025): "Color and Other Constructions: Writings for Jodi L. Sandford" (Alessandria: dell'Orso). 
The code is a step by step guide in the analysis of free-listings through the CSI (Sutrop 2011). It enables researchers to compute salience of items in a list.
